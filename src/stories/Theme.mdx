# Les variables du thème

Chaque valeur ci-dessous est **lue dans le navigateur** sur une racine du thème (`getComputedStyle`), pas recopiée : la table montre ce que `src/theme/minimal.css` pose réellement.

Les valeurs ont été **mesurées** sur le gabarit *Pages* de Revox (fond `#f4f4f4`, texte `#4b4b4b` en Inter 14 px, primaire `#7252d3`, cartes sans bordure détachées par une ombre double, petits titres en Montserrat 10,5 px capitales). Le gabarit n'a pas de surface sombre : la nôtre est dérivée de sa barre latérale.
